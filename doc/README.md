## Per on Comencar

**Si ets un desenvolupador nou** que vol contribuir al projecte:

1. Llegeix [arquitectura/ARQUITECTURA.md](arquitectura/ARQUITECTURA.md) per entendre l'estructura global i com posar en marxa l'entorn de desenvolupament.
2. Revisa [backend/BACKEND.md](backend/BACKEND.md) per coneixer l'API, els models de dades i el sistema de WebSockets.
3. Revisa [frontend/FRONTEND.md](frontend/FRONTEND.md) per entendre l'estructura Angular, les rutes i els components.

**Si ets un usuari final** que vol aprendre a usar l'aplicacio:

1. Llegeix [MANUAL_USUARI.md](MANUAL_USUARI.md) i ves directament a la seccio del teu rol (Professor, Alumne o Administrador).

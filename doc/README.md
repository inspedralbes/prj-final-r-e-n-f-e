# Documentacio del Projecte

Aquesta carpeta conte tota la documentacio del Sistema de Gestio d'Assistencia Escolar.

---

## Indice de Documents

### Per a Desenvolupadors

```
ARQUITECTURA.md   ->  Visio general del sistema: serveis, Docker, flux de dades
BACKEND.md        ->  Models, relacions, tots els endpoints de l'API REST
FRONTEND.md       ->  Estructura Angular, rutes, components, serveis
```

### Per a Usuaris

```
MANUAL_USUARI.md  ->  Guia d'us completa per a professors, alumnes i administradors
```

### Altres

```
DB/               ->  Documentacio de la base de dades
testing/          ->  Informacio sobre els tests (vegeu TESTING.md)
arquitectura/     ->  Diagrames d'arquitectura adicionals
```

---

## Per on Comencar

Si ets un **desenvolupador nou** que vol contribuir al projecte:

1. Llegeix [ARQUITECTURA.md](ARQUITECTURA.md) per entendre l'estructura global.
2. Arrenca l'entorn de desenvolupament seguint els passos del document.
3. Revisa [BACKEND.md](BACKEND.md) per conèixer l'API i els models de dades.
4. Revisa [FRONTEND.md](FRONTEND.md) per entendre l'estructura Angular.

Si ets un **usuari final** que vol aprendre a usar l'aplicacio:

1. Llegeix [MANUAL_USUARI.md](MANUAL_USUARI.md) i ves directament a la seccio del teu rol.
